# PNG/JPG to Rounded-Corner ICO

This is a small Windows utility that requires neither Python nor ImageMagick. It will:

- Crop a square from the center of PNG, JPG, JPEG images;
- Generate rounded-corner transparent edges with 8× supersampling to reduce jagged edges on desktop icons;
- Back the transparent areas of the source image with the icon's dominant color to avoid dark vignetting after scaling;
- Write 7 pieces of 32-bit PNG layers: 16, 24, 32, 48, 64, 128, 256;
- Automatically read the EXIF orientation information commonly found in mobile-phone photos.

## Simplest Usage

Drag image files onto `Execute script&执行脚本.cmd`. Generated `.ico` files are placed in the `修改图标存放` folder in the tool root directory (the folder next to the `.cmd` file).

You can also double-click the `.cmd` file, then select one or more images in the pop-up window.

> **Only drag files onto `Execute script&执行脚本.cmd`.**
> Do not drag onto the `.ps1` inside `_engine`: Windows will not treat `.ps1` as an executable program. Dragging files there will only trigger an error ("not a valid Win32 application") and no conversion will happen.

| File | Purpose |

## What to check if the window flashes and closes instantly

The `.cmd` file is designed to **always pause at the end** with the prompt "Press any key to continue", so normally error messages will not disappear.

If the window still closes immediately, the `.cmd` has not been executed at all (e.g. the files were dragged onto another file). Check `_engine\last-run.log`:

- It contains `launcher started` → the `.cmd` has launched, and the problem lies within the script itself;
- The file does not exist, or the timestamp does not match this run → the `.cmd` was not executed.

## Command Line

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\_engine\png-jpg-to-ico.ps1 .\logo.png
```

Adjustable parameters:

```powershell
# Corner radius: 28% by default; 50% is close to a circle; 0 gives sharp corners
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\_engine\png-jpg-to-ico.ps1 .\logo.jpg -RadiusPercent 28

# Leave a 4% transparent padding around the artwork
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\_engine\png-jpg-to-ico.ps1 .\logo.png -PaddingPercent 4

# Override the default output folder with -OutputDir
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\_engine\png-jpg-to-ico.ps1 .\logo.png -OutputDir .\ico
```

When the `.ps1` is run directly, the default output folder is still `修改图标存放` under the tool root.

## About dark corners

Icons generated by older versions often had a dark rim around the rounded corners: when the source image's own rounded edge was "transparent black", the script mistook that black for the background color and painted the whole rounded rim black. The current version works in two steps:

- **Pick the card color**: count the most frequent opaque color inside the cropped area and use it as the card color; only when nothing can be counted does it fall back to the median color of a small patch inside each corner. The most frequent color cannot be skewed by dark edge pixels or anti-aliased transition pixels.
- **Repaint the rim**: on output, the outer ~6% band, the anti-aliased rounded edge, and the four corners are always repainted with the card color; only near-white, clearly brighter pixels along the edges are kept as the logo.

So even if the source image has black edges, the resulting `.ico` will not have dark corners. This logic is equally safe for **dark icons**: when the artwork itself is dark, the counted card color is the artwork color itself, and the rim will not get smudged.
